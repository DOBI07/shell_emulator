# Shell Emulator

Эмулятор командной оболочки UNIX-подобной ОС с графическим интерфейсом
на Python (tkinter). Этап 1: REPL — минимальный прототип.

## Общее описание

Приложение открывает окно-консоль: пользователь печатает команды прямо в
окне после приглашения `username@hostname:~$`, как в настоящем терминале.
Заголовок окна формируется из реальных данных ОС:
`Эмулятор - [username@hostname]`. Команды `ls` и `cd` — заглушки,
они печатают своё имя и аргументы.

Требуется Python 3.8+ (tkinter входит в стандартную поставку; на Linux
может понадобиться пакет `python3-tk`). Сторонние библиотеки не нужны.

## Функции и настройки

Команды:

| Команда | Описание |
|---------|----------|
| `ls [-l] [-a] [путь ...]` | Заглушка: печатает имя и аргументы. Допустимые ключи: `-l`, `-a`, `-la`, `-al`. |
| `cd [путь]` | Заглушка: печатает имя и аргументы. Не более одного аргумента. |
| `exit` | Закрывает эмулятор. Аргументов не принимает. |

Функции в `src/main.py`:

- `parse_line` — разбор строки на слова с учётом кавычек;
- `cmd_ls`, `cmd_cd`, `cmd_exit` — команды;
- `run_command` — разбор строки и вызов нужной команды;
- `show_prompt`, `replace_input` — работа с приглашением и вводом;
- `on_enter`, `on_up`, `on_down`, `on_key`, `on_backspace`, `on_home` —
  обработчики клавиш;
- `main` — создание окна.

Управление: Enter — выполнить команду, стрелки вверх/вниз — история.
Аргументы с пробелами берутся в кавычки: `cd "my folder"`.

Сообщения об ошибках: неизвестная команда, неверный ключ, лишние
аргументы, незакрытая кавычка (см. примеры ниже).

Настройки внешнего вида (размер окна, цвета, шрифт) — константы в начале
`src/main.py`.

## Сборка и тесты

Сборка не требуется. Запуск (из корня репозитория):

```
run.bat                 # Windows
./run.sh                # Linux / macOS
python -m src.main      # любая ОС
```

Запуск тестов (из корня репозитория):

```
python -m unittest discover -s tests -t . -v
```

## Примеры использования

```
user@host:~$ ls
ls: аргументы = []
user@host:~$ ls -l "my dir" docs
ls: аргументы = ['-l', 'my dir', 'docs']
user@host:~$ cd 'Мои документы'
cd: аргументы = ['Мои документы']
user@host:~$ cd a b
cd: слишком много аргументов
user@host:~$ ls -z
ls: неверный ключ -- '-z'
user@host:~$ pwd
pwd: команда не найдена
user@host:~$ cd "abc
ошибка разбора: не закрыта кавычка "
user@host:~$ exit 1
exit: команда не принимает аргументов
user@host:~$ exit
```

После `exit` окно закрывается.
